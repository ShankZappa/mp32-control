# Project artwork

The icons in this directory are project artwork supplied for MP32 Control by the project
owner. They are included with the project under the repository's MIT License.

They do not contain official Antelope Audio application assets. Product names in nearby
documentation are used only to identify hardware compatibility.

`bmc-mark.png` is the Buy Me a Coffee cup, extracted from `buymeacoffee-qr.png` — which
that service generated for this project's own page — and stored as an alpha mask so the
header can fill it with its own colour. `buymeacoffee-qr.png` is kept as the source it came
from; it is no longer displayed. The mark is Buy Me a Coffee's, used only to identify the
service the link points to.
